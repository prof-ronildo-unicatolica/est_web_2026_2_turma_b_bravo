# Gestão de Projeto e Documentação Interna — Equipe Bravo

Bem-vindo à central de gestão da **Equipe Bravo (7 Integrantes)** na disciplina de **Estágio II em Desenvolvimento Web (2026.2)**.

Este diretório contém todos os documentos de governança, padrões de código, divisão de papéis, roteiro diário e acompanhamento do backlog da equipe ao longo das Sprints do semestre.

## 📁 Estrutura de Documentos de Gestão

* 🏷️ **[01. Padronização de Nomenclaturas e Git Flow](./01_padroes_nomenclatura.md)**
  * Regras obrigatórias de nomenclatura de branches, convenção de commits (`Conventional Commits`) e processo de revisão de Pull Requests (PRs).
* 👥 **[02. Organização da Equipe e Divisão de Papéis](./02_divisao_atividades_equipe.md)**
  * Composição da Equipe Bravo com os 7 integrantes, divisão por frentes técnicas (Backend, Frontend, Banco de Dados, QA/DevOps) e Matriz RACI.
* 📋 **[03. Backlog de Tasks e Sprints](./03_backlog_tasks_sprints.md)**
  * Detalhamento das tarefas técnicas por Sprint, critérios de aceite (DoD) e acompanhamento de progresso.
* 📦 **[04. Guia de Clone do Repositório](./04_guia_clone_repositorio.md)**
  * Instruções detalhadas para clonar o repositório oficial e configurar remotes no ambiente local.
* 📘 **[05. Playbook de Execução Diária](./05_playbook_execucao_diaria_equipe.md)**
  * Cronograma diário das 17 tarefas (Sprints 1 a 6), anel fechado de Code Review entre os 7 integrantes e mapeamento de arquivos.
* 🛠️ **[06. Guia Prático de Execução das Tasks](./06_guia_execucao_pratica_tasks.md)**
  * Manual com comandos rápidos de terminal (copiar e colar) para checkout, commit, push e abertura de PRs com revisores definidos.
